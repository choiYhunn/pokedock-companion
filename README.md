# PokéDock Companion

A personal bedside/desk companion whose everyday utilities are expressed through Pokémon-themed interactions.

## Features
- 4.3" touch clock / ambient home
- focus timer
- NFC Pokémon mode switching
- phone-dock detection
- ambient lighting
- Qi wireless charging
- random encounters / Dex
- birthday-only special event

## Hardware
- **HMI:** Waveshare ESP32-S3-Touch-LCD-4.3C-BOX (SKU 33630)
- **Dock node:** ESP32-C3
- **Sensors:** PN532 + VL53L0X + BH1750
- **Lighting:** WS2812B/SK6812
- **Transport:** ESP-NOW
- **Charging:** independent protected Qi charger
