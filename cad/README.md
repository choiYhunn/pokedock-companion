# CAD notes
- HMI BOX rear mounting spacing: 75 mm.
- Case external size is approximately 116.3×79 mm from current reseller/spec listings.
- V2 base reserves 118 mm HMI plate width.
- Qi tray assumes Samsung EP-P2400 91×91×18.3 mm, with ~2.5 mm XY clearance.
- Qi tray is deliberately shallow so charger remains removable and ventilated.
- Do not permanently encapsulate wireless charger in PLA.
- NFC pad is physically on the opposite side from the Qi coil to reduce coupling/interference.
- Print PETG if bedside temperature/sun exposure is expected; PLA+ is acceptable for normal indoor use.
