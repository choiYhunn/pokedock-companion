## Day 1 / 정확한 SKU 수령

1. **영수증·판매 페이지 보관**: 모델은 **ESP32-S3-Touch-LCD-4.3C-BOX**, Waveshare **SKU 33630**, 800×480 터치, 기존 케이스 포함이다. 일반 4.3/4.3B/4.3C case-less 제품이면 진행하지 않고 교환.
2. 포장 개봉: 액정 파손, 뒷면 케이스, USB-C, SD/RTC, DC 전원 단자, BOOT/RST, 홀(개수/치수/나사 깊이)을 매크로 사진으로 기록. 보드 자체를 드릴링하거나 인서트 깊이를 추정해 볼트 체결하지 않음.
3. 제조사 회로/예제의 **해당 보드 PCB 리비전**을 저장하고 SHA를 기록. 공식 factory BIN이 있는지 확인하고 기존 플래시를 덮어쓰지 말고 복구 순서를 먼저 문서화.
4. 동봉 여부 확인: CR927/16핀 커넥터/스피커/절연선. 부족한 소모품만 구매. CR927의 홀더 극성을 보드 표기로 확인.
5. DMM 사용 전원 점검: **전원이 꺼진 상태**에서 어댑터 정격 12V2A 후보의 출력과 라벨의 +/−, 실물 HMI 단자의 +/−, 절연 피그테일/클램프 종단을 서로 대조. 불명확하면 **전원 인가 금지**.
6. 케이스 후면 USB/SD/전원 선 접근로는 독립된 서비스 홈을 남길 것. MagSafe PD를 12V 전원 단자에 직접 연결하지 않는다.

## Day 2 / Waveshare factory baseline

1. 정상 절연 전원을 연결해 factory 화면 시동, 리셋/온도/비정상 냄새 감시.
2. 제조사 첫 화면 LCD + GT911 터치로 상하좌우/네 꼭짓점 5회 테스트. 각 점 좌표가 뒤집히면 BSP/회전 설정 확인.
3. RTC PCF85063A 시계/CR927 백업: 시간 설정 후 어댑터 5회 재연결, 신뢰할 만한 시간과 날짜 유지 확인.
4. microSD 예제: 정품 카드 FAT 포맷 준비→마운트/읽기/언마운트 10회, 카드 미삽입 시 크래시·자동 포맷 금지.
5. 제조사 오디오 경로가 실물에 있고 임피던스가 확인된 경우에만 저음량 샘플로 확인. 기기에서 소리가 없더라도 기본 Focus MVP는 유효하다.
6. 60분 단독 동작 중 화면/터치/전원 리셋 기록. 실패하면 펌웨어 포팅을 미루고 OEM 하드웨어부터 복구.

## Day 3 / 개발 PC에서 반복 가능한 펌웨어

1. Windows 11의 VS Code ESP-IDF extension 설치, 사용한 **ESP-IDF 5.5.x 구체적 버전** 저장. 콘솔에서 개발 디렉터리 `firmware/hmi/espidf` 열기.
2. `idf.py set-target esp32s3` → `idf.py menuconfig`에서 Waveshare 샘플 **16MB Flash + Octal 8MB PSRAM** 확인. 공식 4.3C 예제와 빌드 설정이 충돌하면 제조사 예제를 우선.
3. `idf.py build` 성공 후 패키징 바이너리, partition table, warnings, build SHA 기록. **기본 M0는 콘솔 확인**이며, opt-in LVGL demo는 별도 `CONFIG_POKEDOCK_HMI_START=y` 옵션으로 **실제 LCD/GT911 검증 후에만** 활성화.
4. `idf.py -p COMx flash monitor` 실행 전 USB-C 데이터 포트/BOOT/RST가 물리적으로 노출돼 있는지 확인. COMx는 장치관리자 포트명으로 바꾼다.
5. vendor baseline 재플래싱 경로를 최소 한 번 시험하고, 복구 방법/버전/날짜를 로컬에 기록. 실패시 추가 플래시 금지.
6. LVGL native HOME/FOCUS 버튼은 실제 손가락 입력·터치 방향·화면 밝기 확인 후 메인 기능으로 승격. C++ StudyEngine host PASS만으로 실기 UI PASS 선언 불가.

## Day 4 / 정밀 기구 가공 전 체크

1. **75×39mm 제조사/판매처 참고 홀 간격은 나사 규격·스레드 길이 증명이 아니다.** C-BOX 실물 마운트 중심 2축·홀 개수/규격/유효 깊이 기록.
2. iPhone 14 Pro 케이스의 카메라 돌출 위치를 실측. 70° 지지 립은 하단 긴 변에 평판 소프트 패드로 닿고, 충전기 없이도 30회 거치 시 미끄러지지 않아야 한다.
3. 별도 MagSafe puck의 실물 **D/T/케이블 출구·최소 굽힘**과 실제 충전 중심을 표시한다. 인쇄물의 57mm Ø는 구형 **가정값**이므로 가공에 사용하면 안 된다.
4. 일체형 큰 케이스가 아니라 **OEM 디스플레이 원형 유지 + 작은 후면 랙 + 교체형 패드/충전기 캐리어** 구조로 PETG/아크릴/상용 스탠드 중 가장 간단한 한 방식을 선택한다.
5. 가공 전: 도면 전체 XY 폭·깊이/높이, C-BOX 후면 USB/DC/SD/RST 서비스 창, 충전 케이블 압박 여부, 후면 무게중심/마찰 테스트 결과를 첨부한다. 한 항목이라도 없으면 최종 출력 견적 발주 금지.

## Day 5 / (선택형) MagSafe 추가

1. 기보유 충전기 우선. 새로 산다면 Apple A3502 1m 완제품/인증 대안 중 실제 부피·케이블 장력·발열이 맞는 하나만 사용.
2. 독립 USB-C PD 20W+ 어댑터에 충전기를 먼저 연결하고, 케이스 장착 iPhone을 올려 충전 표시 확인. 앞면에 아크릴/3D 출력 단열재를 덮지 않는다.
3. 최소 60분, HMI도 켠 상태에서 충전 유지/배터리 충전 알림/체감 열/온도변화/터치·Wi-Fi 오류/떨림 여부 기록. 위험 징후가 있으면 즉시 중단하고 **패시브 A로 되돌림**.
4. 후면 캐리어는 나사 분해 가능해야 하고 충전기를 분리해도 자립 상태, 냉각·서비스·책상 공간 유지.
5. 아이폰 충전 퍼센트를 임의 MCU에 표시하지 않는다. MagSafe 자석이 있다는 것과 실제 배터리 충전 상태는 다르다.

## Final Q0 / 포장 전

기본 기능 시계·Focus·일반 타이머, 전원 차단 후 데이터 정합성, 화면 오조작/야간 눈부심, 30회 탈착, 충전 60분(설치된 경우), 무선 네트워크/SD 없는 상태, USB 복구, 프라이버시 소거, 4시간 계측/안전 감시, 추가 8시간 idle soak을 검사. 매일 쓸 물건이므로 실패한 선택 기능은 끄고 핵심 기능이 안전하면 기본형을 선물한다. 테스트 기록과 사유를 [시험 매트릭스](V14_TEST_PROTOCOL.md)에 남긴다.
