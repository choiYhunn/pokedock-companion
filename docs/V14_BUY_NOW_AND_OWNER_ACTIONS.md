## 사용자에게 필요한 정확한 순서
1. **필수 주문 1개:** 제조사 [Waveshare 4.3C](https://www.waveshare.com/product/esp32-s3-touch-lcd-4.3c.htm)의 선택란에서 **With plastic case / SKU 33630** 1개를 선택. **33799 bare / 4.3B / 구형 4.3 절대 선택 금지.** 상품군 표시는 US$39.99~45.99이나 케이스 옵션과 배송비는 최종 장바구니에서 확인.
2. **재사용 먼저:** USB-C 데이터 케이블, 줄자/캘리퍼, 각도기·폼보드, 멀티미터 보유 여부 확인. microSD 16~32GB와 CR927 코인셀은 박스 동봉 확인 후 구매.
3. **전원 구매는 33630 실물/핀 표기 확인 후:** 절연형 12V 2A DC 안정화 공급기 후보는 보드의 7~36V 단자 **실물 DC+/DC−/커넥터 타입** 확인 뒤 구매하고 종단한다. USB-C에 12V를 연결하면 안 된다.
4. **휴대폰 실측 5개:** iPhone 14 Pro에 평소 MagSafe 케이스를 장착하고 L, W, 케이스 실제 최대 T, 카메라 돌출 위치/두께, 설치할 책상 남는 후면 깊이(mm) 측정. **65°/70°/75° 종이/폼보드 목업**으로 앉은 시야/한 손 집기/낙하 확인.
5. **MagSafe 후구매:** 기보유 Apple/인증 Qi2 완제품 puck 및 20W+ PD가 있으면 먼저 써 보고 60분 충전/케이스 간섭/열 시험. 없다면 Apple A3502 원본(65,000원) 한 개만 고려하되, 패시브 목업 공간 검증 전에 주문하지 않는다.
6. **후반부 보류:** 3D 프린팅, 아크릴 가공, 체결 볼트, 충전기 홀더, ESP32-C3, PN532 NFC, LED, 별도 RTC, 스피커 구매 금지. 실물 검증 후 소량 발주.

## 미완성 경계
호스트 C++/Node/OpenSCAD 테스트 및 ESP-IDF LVGL9 시제품 크로스빌드는 통과했지만 **실물 화면 터치·RTC/NVS·충전·전도 안전·펌웨어 재플래시는 아직 통과하지 않았다**. 최종 3D 출력 제작 파일/나사 길이·DC screw terminal 물리 pin 번호를 실측 없이 확정할 수 없다. 인증 어댑터 출력 +/−와 보드의 실제 VIN/GND 표기는 스스로 찍은 사진·회로도와 DMM으로 대조해야 한다. 합격 기준을 건너뛰지 말 것.

## 후속 설계에 필요한 사진
- 케이스 장착 아이폰의 앞·뒤(자/캘리퍼와 촬영), 카메라 부위 근접.
- 수령한 33630 뒷면의 전원 단자·나사홀·USB/SD/BOOT/RST 확대.
- 실제 사용할 충전기 모델·표기·케이블 출구. 충전기 없으면 현재는 생략.
