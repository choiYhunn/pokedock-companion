# Pokémon Fan-system V4

## Product thesis

PokéDock must not feel like a productivity dashboard with Pokémon wallpaper.
Pokémon is the interaction model itself.

## Main loop

`Quest -> Train -> EXP/Bond/Egg -> Encounter -> Dex/Badge -> Partner Center`

## Persistent navigation — V6

Only three controls remain persistent:

1. HOME — time/date, Partner, next training, compact daily status
2. central Poké Ball MENU — opens grouped secondary functions
3. DEX — direct collection access

Poké Ball menu groups:
- TRAIN — Focus / Timer / Stopwatch
- JOURNEY — Quest / Trainer / Egg / Badges / Record
- DESK — Weather / Alarm / Light
- LINK — Phone / NFC / Settings

Birthday is not part of the everyday menu. It is event-driven.

The goal is progressive disclosure: daily use should require very few decisions, while all secondary functions stay reachable in one or two taps.

## Partner roles

- Togekiss: calm / Center
- Lucario: training / Focus
- Gengar: night
- Pachirisu: phone charging / electric
- Togepi: morning / alarm
- Jirachi: birthday / wish

## Progression

- Study EXP: earned from valid Focus sessions
- Bond: increases through training and partner interactions
- Mystery Egg: progress mainly from Focus; hatch reveals a Dex entry
- Random Encounter: post-Focus reward roll
- Shiny: rare cosmetic encounter state; no paid mechanics
- Trainer Badge: original PokéDock study achievements, not replicas of official Gym badges

## Original PokéDock badges

- FOCUS
- STREAK
- ROUTINE
- NIGHT
- DEX
- WISH

## NFC

A tag/figure can summon a mapped Partner, dialogue, light theme and preset.
Example: Gengar tag -> Night Buddy + ghost palette + night-focused dialogue.

## Birthday

Jirachi runs a one-day Wish Event and can grant the WISH ribbon/badge.
The romantic message remains an Easter egg rather than replacing the everyday utility.

## Visual language

- Poké Ball-inspired confirmation control
- Pokédex number/type chips
- locked silhouettes
- Partner speech bubble
- Trainer Card
- custom badges
- encounter reveal
- theme-specific ambient palettes

Avoid reproducing one official game UI pixel-for-pixel; use the franchise vocabulary as fan-project inspiration while keeping the layout original.
