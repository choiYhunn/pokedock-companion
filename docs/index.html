상황을 눌러서 제품 경험 비교

포켓몬은 장식이 아니라 상태 머신의 UI 캐릭터다. 한 상태가 다른 상태를 덮어쓸 때 우선순위도 실제 펌웨어와 동일하게 설계한다.

지금 고정한 디자인 원칙

마음에 안 드는 걸 말하면 다음 커밋에서 바로 바꿀 수 있다.
01
포켓몬 굿즈보다 전자제품

화이트/크림 하우징, 작은 포켓몬 요소. 방에 계속 두어도 유치하지 않게.

02
로맨스는 Easter Egg

평소엔 실용 기기. 생일과 숨겨진 NFC에서만 개인 메시지가 열린다.

03
포켓몬이 기능을 담당

파치리스=충전, 루카리오=집중, 팬텀=야간처럼 행동과 캐릭터를 연결.

04
3D 프린트는 옵션

기성 스탠드로 먼저 완성하고, 최종 외형이 아쉬울 때만 전용 베이스를 출력.

V1에서 실제로 매일 쓰게 만드는 것

기능 수를 늘리는 것보다 하루에 몇 번이라도 자연스럽게 만지는 이유를 만든다. 그래서 첫 버전은 아래 세 축에 집중한다.

⚡

Phone Dock

휴대폰을 내려놓는 물리 행동 자체가 파치리스 이벤트가 된다. 충전 패드가 그냥 충전기가 아니라 캐릭터 인터랙션으로 느껴진다.

◎

Focus / Clock

시계와 포모도로는 장식이 아니라 상시 기능. 집중 모드에서는 루카리오가 나타나고 랜덤 이벤트는 자동으로 정지한다.

✦

Birthday Secret

365일 중 하루만 일반 상태보다 우선순위가 높은 지라치 이벤트가 열린다. 사진첩 대신 짧은 메시지와 포켓몬 합류 연출로 끝낸다.

두 MCU로 나눈 이유도 제품 완성도 때문이다

화면과 센서를 한 보드에 억지로 모으기보다 HMI와 Dock을 분리해 하루 조립의 실패 지점을 줄인다.
