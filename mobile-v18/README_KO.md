# PokéDock Mobile V18

V17.1의 화면과 디자인(색, 폰트, 둥근 카드, 세로 일상 화면과 가로 게임 화면)은 그대로 두고, 그 위에 포켓몬 도감, 미니게임 7종, 타이머·알람 확장, 파트너 친밀도, 마스터볼 M6 BLE 연동을 더했습니다.

- 미리보기 경로(병합 후): `https://choiyhunn.github.io/pokedock-companion/mobile-v18/`
- 기존 `mobile-v17/` 경로는 **바꾸지 않았습니다.** 두 앱은 같은 origin을 쓰지만 V18은 `pokedock-v18-*` 저장소와 캐시만 사용하고, 첫 실행 때 V17.1 데이터를 **복사**해 옵니다(V17 데이터는 그대로 남음).
- 로컬 미리보기: 저장소 루트에서 `python -m http.server 8718` → `http://127.0.0.1:8718/mobile-v18/`

## 배포 경로 결정

GitHub Pages는 `main` 브랜치 루트(legacy)에서 배포됩니다. 따라서 이 브랜치는 **병합 전까지 공개되지 않습니다.** `mobile-v17/`을 덮어쓰는 대신 별도 `mobile-v18/`을 만든 이유는 다음과 같습니다.

1. V17.1 홈 화면 아이콘을 설치한 사용자의 앱이 깨지지 않습니다.
2. 병합 후 두 버전을 나란히 비교할 수 있습니다.
3. 같은 origin이라 V17.1의 알람·편지·파트너 설정을 V18이 자동으로 옮겨 올 수 있습니다.

GitHub Actions, 서버, 외부 DB, 로그인 기능은 추가하지 않았습니다. 루트 `index.html`에는 V18 링크 버튼만 추가했고, 휴대폰 자동 이동은 여전히 V17.1로 갑니다.

## 타이머

- 15/25/45분 유지 + 사용자 지정(1–120분) + 포모도로(집중·휴식·긴 휴식·세트 수 설정, 휴식 자동 시작 선택)
- **종료 시각(`endAt`)을 저장**하고 남은 시간은 매번 계산합니다. 화면 잠금, 탭 절전, 앱 재시작, 다른 화면이나 게임을 열어도 어긋나지 않습니다. 앱이 꺼져 있는 동안 끝난 집중과 휴식도 순서대로 정산합니다.
- 오늘, 이번 주(7일 막대 그래프), 누적 집중 시간과 완료 세션. 1분 이상 하다가 초기화한 집중도 시간으로 기록합니다(세션 수에는 포함하지 않음).
- 시작할 때 파트너가 응원하고, 끝나면 축하 동작과 친밀도 +2. 문구는 부담 주지 않는 말투로 썼습니다.
- 네이티브 앱은 종료 시각에 로컬 알림을 예약합니다. 마스터볼이 연결되어 있으면 집중 시작·일시정지·재개·초기화를 볼과 동기화합니다.

## 알람

- 최대 8개, 요일 반복, 이름, 기존 소리 3종 유지
- 추가: 알람별 포켓몬, 소리, 스누즈(없음/5/10/15분), 일반·조용한 알람, 미리 듣기, 아침 인사 화면 미리보기, 다음 알람과 남은 시간, 같은 시각·요일 중복 경고
- 웹: 화면이 열려 있을 때만 울립니다. 이 제한을 알람 화면에 적었습니다. 탭이 잠시 멈춰도 2분까지는 따라잡고, 하루 한 번만 울립니다. 자정 경계를 처리하고, 이미 지난 시각에 켠 알람이 바로 울리지 않게 했습니다.
- 네이티브(Android): `LocalNotifications` 주간 반복(ID `10000+i*20+요일`), 소리별 채널, 조용한 채널(중요도 2), 스누즈·끄기 액션, 정확한 알람 권한 확인
- M6: 볼은 매일 반복되는 알람 1개만 저장합니다(프로토콜 v2). 그래서 앱은 24시간 안의 다음 알람만 보냅니다. 자세한 내용은 [`docs/M6_PROTOCOL_V3_PROPOSAL_KO.md`](docs/M6_PROTOCOL_V3_PROPOSAL_KO.md)에 있습니다.
- 앱 업데이트 뒤에도 알람이 유지됩니다(V17 → V18 마이그레이션 테스트 포함).

## 파트너와 매일 지내기

- 터치하면 포켓몬별 대사와 동작을 보여 줍니다. 팬텀은 장난스러운 대사가 따로 있고, 밤 10시 이후 팬텀과 놀면 배지를 받습니다.
- 파트너 룸 동작: 인사, 점프, 춤, 장난, 축하, 잠자기. 실제 gen-V 애니메이션 GIF는 V17과 같이 정수배 확대합니다.
- 친밀도(레벨 10단계, 쓰다듬기 하루 5회 상한), 함께한 날짜, 연속 방문, 배지 10종, 새 포켓몬 발견, 오늘의 미션
- 생일(MM-DD)과 기념일을 입력하면 그날 인사말, 서랍 카드, 축하 동작이 바뀝니다. 다섯 번 쓰다듬기 이스터에그는 유지했습니다.
- **개인 메시지는 이 기기의 localStorage에만 저장합니다.** 저장소에는 기본 예시 문구만 있습니다. 사용자가 원하면 마스터볼로 보낼 수 있습니다(90바이트, 한글 약 30자).

## 오프라인과 저장

- 앱 화면(모듈 23개, 아이콘, 소리 3개)은 서비스워커가 릴리스별 캐시에 저장합니다. 새 버전이 나오면 V18 이전 셸 캐시만 지웁니다(V17 캐시는 건드리지 않음).
- 포켓몬 이미지 48개(24종 × 아트·픽셀)는 첫 온라인 접속 때 자동 저장됩니다. gen-V 픽셀 GIF가 없으면 Showdown GIF로 대체합니다.
- 울음소리 24개는 사용자가 **설정 → 오프라인 콘텐츠**에서 직접 저장할 때만 기기에 남습니다. 저장하지 않았다면 퀴즈에서 안내합니다.
- 저장 공간 사용량 표시, 이미지·울음소리 캐시 지우기, 용량 부족(`QuotaExceededError`) 안내를 넣었습니다.
- 데이터는 localStorage JSON 하나(`pokedock-v18-state`)에 둡니다. 기록 양이 작고 제한이 있어(일별 기록 120일, 밸런스 60개, 오답 40개) IndexedDB는 쓰지 않았습니다.

## 권리 표기

포켓몬 이름, 이미지, 울음소리의 권리는 Nintendo, Creatures, GAME FREAK에 있습니다. 이 저장소에는 포켓몬 이미지·음원 파일이 없습니다. 앱이 실행될 때 PokeAPI의 GitHub 저장소(`PokeAPI/sprites`, `PokeAPI/cries`)에서 불러옵니다. PokeAPI가 파일을 공개한다고 해서 재배포가 허락된 것은 아닙니다. 그래서 울음소리는 기기 캐시만 허용하고, 네이티브 빌드에도 넣지 않습니다. 화면 캡처도 공식 아트가 들어 있어 저장소에 올리지 않았습니다. 알람 소리 3개와 게임 효과음(Web Audio 합성)은 PokéDock이 직접 만든 것입니다.
