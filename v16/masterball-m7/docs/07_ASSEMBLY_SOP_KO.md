# 07. 조립 SOP (출력하는 부품과 사는 부품의 구분 포함)

## 도구

| 도구 | 비고 |
|---|---|
| 정밀 드라이버 (+0, +1), 육각 | M2·M3 나사 |
| 순간접착제(CA, 젤형), 이소프로필 알코올 | 자석, 버튼, 링, 귀 보조 |
| 핫멜트 건(저온) | 센서, 부저 포켓 |
| Ø2.95 / Ø3.3 드릴 날 + 핸들 | 핀 구멍 손질 |
| 핀셋, 니퍼, 케이블 타이 | |
| 멀티미터 | 납땜 후 단락 검사 |
| (납땜 공정만) 인두, 땜납, 수축튜브, 열풍기 | **학교 지도 또는 외주** |

## 출력하는 부품 (D군, 12종)

뚜껑, 라이너, 귀 2, 벨트, 하단 쉘, 덱, 베젤, 크래들, 스토퍼 블록, 버튼 링, 버튼.

## 사는 부품 (A·B·C군)

보드, 부저 회로, 리드 센서와 액추에이터, USB 어댑터와 연장 케이블, 1.27 소켓, 핀, 자석, 나사, 와셔, 발, 테이프. 목록은 `bom/BOM_M7.csv`에 있습니다.

## 순서

| 단계 | 작업 | 확인 |
|---|---|---|
| S0 | 보드를 USB-C로 PC에 연결해 공장 데모가 뜨는지 확인. 실물 치수 측정(`fitkit` 양식) | 화면, 터치 |
| S1 | FirstInstall로 m7-0.5.0-gift 설치 (`docs/05`). 책상 위에서 보드 단독 | 팬텀 표시, 시계 |
| S2 | 시험편 FK1–FK5 출력·측정 → 합격 | `FIT_MEASUREMENT_FORM.csv` |
| S3 | 본 출력 C1–C7 | 서포트 위치 |
| S4 | 하단 쉘: 바닥 포켓에 와셔 3장 CA 접착 → 실리콘 발 8개 → 부저를 포켓에 넣고(+핀이 위) 핫멜트 한 점 | 와셔가 흔들리지 않음 |
| S5 | 벨트: 핀 구멍 손질 → 자석 2개(극성 표시 확인) CA → 리드 센서를 안쪽 포켓에 밀어 넣고 핫멜트(리드선은 아래로) → 스토퍼 블록을 M2 PT 2×8 2개로 아래에서 체결 | 센서 윗면이 덮개 바로 아래 |
| S6 | **납땜 공정 (학교 지도·외주)**: 구동 기판(AO3400A, 100 Ω, 100 kΩ, 1N4148), 1.27 소켓 J1-4·6·8·10에 전선, PTC 직렬, 센서 리드 연결, 수축튜브 | 멀티미터: 5 V–GND 단락 없음, IO17–GND는 자석을 대면 0 Ω, 떼면 개방 |
| S7 | 뚜껑: 자석 2개(벨트 자석과 서로 당기는 극성) CA → 액추에이터를 포켓에 CA → 귀를 안쪽에서 M2 PT 2×8 + CA 한 점 → 라이너 M2 PT 2개 | 귀 방향 핀 맞음 |
| S8 | 벨트를 하단 쉘에 얹고(스피곳) 버튼 링과 버튼 위치를 맞춰 CA. 벨트–하단은 CA 4점(분해가 필요 없음) | 테두리 단차 없음 |
| S9 | 힌지: 뚜껑 너클을 벨트 너클 사이에 맞추고 Ø3×30 핀을 한쪽에서 압입. 양끝이 너클 안으로 0.4 mm 들어가야 함 | 0–110° 부드럽게 돌고 110°에서 멈춤 |
| S10 | 포드: 보드를 베젤 컵에 넣고(유리가 립 쪽) → 크래들 판을 스탠드오프에 M2×6 접시 4개 → 판과 베젤을 M2 PT 3개 | 유리가 립에 닿지 않음(0.6 mm) |
| S11 | 내부 커버 위에 포드를 놓고 크래들 발판(M3×10 납작머리 2)과 측면 브래킷 발(M3×10 접시 2)을 바닥에 체결. 너트는 바닥 아래 육각 포켓 → 커버를 뒤집어 ㄱ자 어댑터를 보드 USB-C에 아래에서 꽂음 → 연장 케이블 연결 → 구동 기판을 바닥 아래에 1 mm 폼테이프로 → J1 소켓을 보드에 꽂음 | 어댑터가 바닥 가장자리에 받쳐짐 |
| S12 | 연장 케이블 패널 커넥터를 후면 구멍 Ø22에 너트로 고정 → 케이블을 바닥 마운트에 타이로 → 센서 리드는 내부 커버 벽 바깥 틈으로 바닥 아래까지 | 뚜껑 스윕 영역에 선 없음 |
| S13 | 내부 커버(최대 Ø122.8)를 벨트 구멍(Ø124)으로 위에서 넣고 M3 PT 3×10 접시 3개로 기둥에 체결. 리드 센서 선은 벽 바깥 틈(2.8 mm)으로 | 커버 립이 띠 윗면보다 0.6 mm 낮음 |
| S14 | 전원: KC 5 V 어댑터를 후면 포트에 → 화면, 부저 → 뚜껑을 닫으면 1초 안에 화면 꺼짐, 열면 팬텀 등장 | 로그 `lid opened/closed` |
| S15 | 실물 전도 시험 (110°, 화면 중앙 1.5 N), 24시간 동작, 내부 온도 | `docs/08` 실물 항목 |

## 분해

내부 커버 나사 3개를 풀면 커버와 포드가 함께 올라옵니다. 이때 배선은 연결된 채로 둡니다(여유 루프). 힌지 핀은 반대쪽에서 Ø2.5 핀으로 밀어 빼냅니다.
