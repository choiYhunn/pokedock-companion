# 11. 주말(11월 21–22일) 출력 계획 — 시험편 먼저

> 아래 시간과 재료량은 **Bambu Studio 2.5 CLI로 실제 슬라이스한 추정치**입니다(`tools/bambu_slice_estimate.py`, 2026-11-16).
> - 기준: X1C, 0.4 노즐, Bambu PLA Matte 프로파일
> - 실물 출력은 아직 하지 않았습니다.
> - 뚜껑(C1)의 "돔 안쪽만 서포트" 칠하기는 CLI에서 할 수 없습니다. 그래서 C1의 서포트 재료는 실제보다 많게 잡힌 **상한값**입니다.
