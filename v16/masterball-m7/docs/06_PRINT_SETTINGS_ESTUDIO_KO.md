# 06. 성균관대 E-Studio 출력 안내 (Bambu Studio, PLA 전용, AMS 없음)

> **본 출력 잠금**: `print/02_final_LOCKED_until_appearance_approval/`은 외관 승인 게이트(`appearance/`)가 APPROVED가 될 때까지 출력하지 않습니다. 시험편(`01_fitkit_first`)은 지금 출력해도 됩니다. 귀 위치를 B로 고르면 C1(뚜껑)과 C4(귀)는 `print/variant_B_ears_photo_position/`을 씁니다.

- **전제**: 학생 출력은 X1C/H2S, **PLA만**, 단색 출력입니다(AMS 다색을 전제하지 않음).
- **판 크기**: 모든 부품이 180 mm 정육면체 안에 들어갑니다. 판 구성은 256 mm(X1C) 기준입니다. A1 mini(180)에서는 C3과 C6을 각각 두 판으로 나눕니다.
- **3MF 내용**: `print/`의 3MF와 STL은 출력 방향으로 눕혀 바닥(z = 0)에 놓은 상태입니다. 3MF에는 형상과 방향만 들어 있으므로 아래 설정은 Bambu Studio에서 직접 지정합니다.

  - 꼭대기 안쪽 8,441 mm²는 라이너 위쪽이라 가려집니다.

## 3. PETG가 꼭 필요한 부품이 있나?

| 부품 | 하중·온도 | 판정 |
|---|---|---|
| 크래들 (`display_cradle_plum`) | 보드 약 20 g, 터치 약 2 N. 내부 온도는 닫으면 화면이 꺼져 낮음 | **PLA 가능.** PETG는 선택 사항 (내부 45 °C 이상이 측정되면 전환) |
| 힌지 너클 (벨트, 뚜껑) | 핀 회전 마찰, 스토퍼 약 10 N | PLA 가능. FK2에서 200회 개폐로 확인 |
| 스토퍼 블록 | 면 접촉 압축 | PLA 가능. 나사로 교체 |
| 나머지 외관 | 하중 없음 | PLA |

결론: **PETG가 반드시 필요한 부품은 없습니다.** 한 곳의 조건만 기록해 둡니다. 직사광선 아래 창가에 두지 말 것(PLA 연화 약 55 °C).

## 4. 출력 후 손질

- 벨트 핀 구멍: 핀이 들어가지 않으면 Ø2.95 드릴을 손으로 돌려 1회 통과시킵니다(전동 드릴 금지).
- 뚜껑 너클 구멍: Ø3.3 회전. 핀이 걸리면 Ø3.3 드릴로 1회.
- 서포트를 뗀 면(뚜껑 안 꼭대기, 벨트 턱)은 400방 사포로 정리합니다. 외관 곡면은 손대지 않습니다.
- 출력물 모서리는 손이 닿는 곳만 디버링 도구로 0.3 mm 정리합니다.
