# 09. 최종 사용자 실행 체크리스트

## 주문 전

- [ ] `bom/BOM_M7.csv`의 **A군**만 주문합니다: Waveshare SKU 30106 × 1, Digi-Key 묶음.
- [ ] 보드 품번이 **SKU 30106 (ESP32-S3-Touch-AMOLED-1.43, 케이스 없음)**인지 확인합니다. 1.43-B, 1.43C는 안 됩니다.
- [ ] 실제 구매는 직접 합니다(이 저장소는 주문하지 않습니다).

## 보드 도착

- [ ] USB-C로 PC에 연결하면 공장 데모 화면이 뜹니다.
- [ ] `fitkit/FIT_MEASUREMENT_FORM.csv` B1–B4를 측정합니다: 유리 지름, 스탠드오프 간격, 헤더 높이, USB-C 위치.
- [ ] `docs/05` §2의 FirstInstall을 실행합니다. **공장 백업 파일을 비공개 폴더에 보관합니다.**
- [ ] 팬텀(비공개 팩)과 시계가 보입니다.

## 학교 출력

- [ ] 시험편 FK1–FK5를 출력합니다(`docs/06` 순서) → 측정 양식 F1–F12를 채웁니다.
- [ ] 불합격 항목은 `cad/m7_params.py` 값을 바꾸고 `tests/run_m7.sh`를 다시 실행합니다(CAD PASS 유지 확인).
- [ ] 본 출력 C7 → C6 → C3 → C4 → C5 → C2 → C1 순서로 진행합니다.

## B·C군 주문 (시험편 합격 후)

- [ ] 1.27 mm 2×7 소켓: 실측 헤더 끝과 BOOT/RESET 사이 간격 0.25 mm 이상인 제품을 고릅니다.
- [ ] Adafruit 4432 + 4218: 도착하면 PC와 보드 사이에 연결해 COM 포트가 잡히는지 봅니다(데이터 통과 확인).
- [ ] Ø3×30 SUS 평행핀, N35 Ø6×2 자석, 나사, M20 대와셔 3장, 실리콘 발.

## 조립과 시험

- [ ] `docs/07` S4–S14를 진행합니다. **S6 납땜은 학교 지도 또는 외주**로 합니다.
- [ ] 뚜껑을 닫으면 1초 안에 화면이 꺼지고, 열면 팬텀이 등장합니다.
- [ ] 110°로 열어 화면 중앙을 눌러도 넘어지지 않습니다(S15).
- [ ] 알람이 울리고 집중 25분이 끝나는지, 5번 탭하면 메시지가 나오는지 확인합니다.
- [ ] 24시간 연속 동작, 닫힌 상태 내부 온도를 기록합니다.

**완료 판정**: 위 항목을 모두 실물로 확인하기 전에는 "선물 완성"으로 표시하지 않습니다.
