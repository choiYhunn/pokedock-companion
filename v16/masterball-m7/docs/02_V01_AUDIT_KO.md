# 02. M7 v0.1 독립 감사

## 입력 상태

- 요청된 `PokeDock_M7_Openable_CAD_v01.zip`이 이 PC에 **없습니다.**
  - Downloads, Documents, Desktop을 모두 검색했습니다.
  - 그래서 v0.1의 `m7_build.py`, STEP/STL, `VERIFY_M7.json`은 읽지 못했습니다.
- 사용한 것은 Downloads에 있던 v0.1 파일 세 개뿐입니다. 없는 자료는 추정하지 않았습니다.
  - `00_READ_FIRST_KO.md`
  - `CAD_PREVIEW_open.png`
  - `CAD_PREVIEW_closed.png`
- M7은 v0.1 코드를 이어받지 않고 M6 소스와 공식 Waveshare STEP으로 새로 작성했습니다.

## v0.1 문제점 (README와 미리보기 기준)

| # | 문제 | 근거 | M7 조치 |
|---|---|---|---|
| 1 | 화면 중심 (0, −22, +3): 낮고 앞쪽이라 정면 버튼과 테두리에 가림 | v0.1 README 표, 사용자 지적 | 중심 (0, −12, 14). 앉은 눈 27곳 광선 검사 100 % |
| 2 | 보드 실물 대신 유리 직경과 구멍 위치만 쓴 프록시 | v0.1 README 미완료 1 | 공식 STEP 부품 295개(유리, PCB, 헤더, USB-C, 스위치, 스탠드오프)로 간섭·광선 검사 |
| 3 | 기계적 스토퍼 없음, 핀 이탈 방지 없음 | 미완료 3 | 나사로 고정한 교체형 스토퍼 블록. 110° 면 접촉 검증(111°에서 2.1 mm³). 핀은 바깥 너클 압입 |
| 4 | USB와 부저 배치 미정 | 미완료 4 | 전원 B안(보드 USB-C + ㄱ자 어댑터 + 후면 패널), 부저 벽 포켓, 구동 기판은 덱 아래 |
| 5 | 탈착식 후방 안정화 발(사진에 없는 돌출) | v0.1 README 안정성 | 숨은 와셔 3장 + 평면 Ø75 + 발 8개. 외부 돌출 없음 |
| 6 | 정면 버튼이 장식이며 띠 위에 떠 있음 | 미리보기 | 링 + 버튼 2부품. 구면에 맞춘 오목 뒷면 + 위치 핀 + 접착 |
| 7 | 귀가 구슬 모양이고 받침면이 없음 | 미리보기 | 평면 자리 + 안쪽 나사 + 방향 핀 |
| 8 | 뚜껑 안쪽 서포트 자국 대책 없음 | README 권장만 | 라이너가 서포트 영역 8,441 mm²를 가림. 열었을 때 보이는 서포트 면 0 mm² |
| 9 | 열림 감지 없음 | — | 리드 센서 + 액추에이터, 펌웨어 화면 ON/OFF |
| 10 | PETG 권장 | README | E-Studio는 학생 출력 PLA 전용이라 전 부품 PLA로 설계하고 평가(`docs/06`) |

v0.1 미리보기 렌더는 메시 셰이딩만 있고 화면 내용이 없습니다. M7 렌더는 실제 메시와 실제 크기 화면을 씁니다.
