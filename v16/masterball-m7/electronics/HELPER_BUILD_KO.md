# 도우미·외주 작업지시서 (v0.6): 납땜 4점

**의뢰인은 납땜하지 않습니다.** 아래 두 가지(H2, H3)를 만들어 시험 기록과 함께 전달해 주세요. 가능하면 소리 케이블의 접점 재배열(H1-A, 납땜 없음)도 부탁합니다.
- 그 밖의 연결(J10 소리 케이블 H1, USB)은 상용 케이블을 꽂기만 하므로 의뢰인이 합니다.
- 배선도: `img/m7_wiring_v06.png`. 핀표: `electronics/M7_PINMAP_KO.md`. 데이터: `electronics/harness_m7.json`.

## H2 — 리드 센서 → J1 소켓 (2점)

1. 소켓의 **1번 핀 위치**를 찾습니다(소켓 표시 또는 데이터시트). 몸통 그 모서리에 흰 점을 찍습니다.
2. 리드 한 가닥을 **10번** 꼬리에, 다른 가닥을 **6번** 꼬리에 납땜합니다.
   - 6번과 10번은 같은 줄(짝수 줄)에 있고 서로 2.54 mm 떨어져 있습니다.
   - 리드에 극성은 없습니다.
   - 리드를 자르지 말고 300 mm 그대로 씁니다. 배선 경로에 약 200 mm가 필요합니다.
3. 각 꼬리에 Ø1.5 수축튜브를 씌웁니다. 소켓 뒷면에 글루건을 아주 조금 발라 당김을 막습니다. 핀 사이로 흘러 들어가지 않게 합니다.
4. 다른 핀(1–5, 7–9, 11–14)에는 아무것도 연결하지 않습니다.

## H3 — 스피커 → DFR0534 (2점)

1. 스피커 + 리드(빨강 또는 + 표시)를 모듈 아랫줄의 **SP+** 패드에, − 리드를 **SP−** 패드에 납땜합니다.
   - 패드는 SPK 소켓 옆, 모듈 아랫줄 "ONE DACR DACL SP− SP+" 중 오른쪽 두 개입니다.
2. 리드를 패드 근처에서 한 바퀴 감아 당김을 막습니다.
   - 모듈 장착 구멍 2개(SPK 쪽 끝)는 막지 않습니다. 의뢰인이 나사로 고정합니다.
3. 모듈의 SPK 2핀 소켓과 Gravity 4핀 소켓은 그대로 둡니다.

## H1-A — 소리 케이블 접점 재배열 (납땜 0, 압착 0, 권장)

준비: Adafruit **4424** (SH 4핀 ↔ PH 4핀, 200 mm), 의뢰인이 그린 두 그림
- J10 쪽: 4424의 각 선이 GND / 3V3 / GPIO44 / GPIO43 중 무엇인지 (`docs/07` S3a)
- 모듈 쪽: Gravity 소켓의 각 자리가 "−" / "+" / "R" / "T" 중 무엇인지 (`docs/07` S3b)

1. PH 하우징(모듈 쪽 흰 플러그) 옆 창의 걸쇠를 가는 바늘(또는 JST EJ-PH 추출 공구)로 누르면서 선을 뒤로 살짝 당겨 접점 4개를 모두 빼냅니다.
   - 접점이 휘지 않게 합니다.
2. 아래 순서로 다시 끝까지 '딸깍' 꽂습니다. 각 선을 살짝 당겨 빠지지 않는지 확인합니다.
   - GND 선 → "−" 자리
   - 3V3 선 → "+" 자리
   - GPIO44 선 → "R" 자리
3. GPIO43 선의 접점은 하우징에 넣지 않습니다.
   - Ø1.5 수축튜브로 접점 끝을 5 mm 넘게 덮어 수축시킵니다.
   - 케이블 쪽으로 접어 Ø3 수축튜브(또는 작은 타이)로 함께 고정합니다.
   - "T" 자리는 비웁니다.
   - 최종 위치는 `img/h1_option_a_wiring.png` 그림대로입니다(모듈 실크 글자 기준).
4. 시험: 플러그를 모듈에 꽂고, 모듈 윗줄 패드와 SH 플러그 쪽 각 선을 도통으로 대 봅니다.
   - GND ↔ GND
   - 3V3 ↔ VCC
   - GPIO44 ↔ RX
   - TX ↔ 아무 데도 연결 없음
5. 인접 단락: PH 접점끼리 6쌍 모두 개방인지 확인합니다(P1). 전원 시험(P2·P3)은 의뢰인이 `docs/04` §6대로 합니다.

재배열이 어렵거나 접점이 손상되면 B안(Adafruit 4397 + 3955 핀 이음, 예비로 함께 구매)으로 갑니다.
