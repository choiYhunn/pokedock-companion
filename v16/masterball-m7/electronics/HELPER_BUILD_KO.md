# 인터페이스 모듈 제작 안내 (납땜 도우미·외주용)

**의뢰인은 납땜하지 않습니다.** 도우미가 아래 모듈 한 개와 부저 리드선을 만들어 전달하면, 의뢰인은 꽂고 나사를 조이고 테이프로 붙이기만 합니다.

- **그림**:
  - 회로도: `img/module_schematic.png`
  - 부품 배치: `img/module_perfboard_layout.png`
- **데이터**: `electronics/interface_module_m7.json` (넷, 핀, 길이. 검사 5/5)
- **회로**: M6에서 검증한 부저 구동 회로 그대로에 뚜껑 센서 입력을 더한 것입니다.

## 1. 부품 (`bom/ELECTRONICS_CONFIRMED_KO.md`)

| 기호 | 부품 | 방향 주의 |
|---|---|---|
| Q1 | AO3400A를 Adafruit 1230 SOT-23 변환 기판에 | 변환 기판 실크 1 = G, 2 = S, 3 = D (AO3400A 데이터시트 핀 1 = G, 2 = S, 3 = D) |
| D1 | 1N4148 | **띠(캐소드) = +5 V 쪽** (TB1의 BZ+) |
| R1 | 100 Ω | 극성 없음 |
| R2 | 100 kΩ | 극성 없음 |
| F1 | MF-R075 PTC | 극성 없음 |
| TB1, TB2 | Phoenix 1935161 나사식 단자 | 전선 넣는 쪽이 기판 바깥(위쪽 가장자리)을 향하게 |
| J1 소켓 | Harwin M50-3000745 (2×7, 1.27 mm) | 1번 핀 모서리에 흰 점을 표시 |

## 2. 연결 (넷 표: 아래면 피복선 점대점, 맨선 교차 금지)

| 넷 | 연결 |
|---|---|
| +5V_IN | 패드 +5V_IN ↔ F1-1 |
| +5V | F1-2 ↔ TB1 BZ+ ↔ D1 캐소드 |
| BZ_DRAIN | Q1 D ↔ TB1 BZ− ↔ D1 애노드 |
| GATE | R1-2 ↔ Q1 G ↔ R2-1 |
| IO16 | 패드 IO16 ↔ R1-1 |
| GND | 패드 GND ↔ Q1 S ↔ R2-2 ↔ TB2 GND |
| LID | 패드 LID_IN ↔ TB2 LID |

## 3. 피그테일 (모듈 → J1 소켓, 각 160 mm, 28 AWG)

| 모듈 패드 | 소켓 핀 | 색 |
|---|---|---|
| +5V_IN | **J1-4** | 빨강 |
| GND | **J1-6** | 검정 |
| IO16 | **J1-8** | 노랑 |
| LID_IN | **J1-10** | 흰색 |

- 4·6·8·10은 모두 짝수 열에 있고 서로 이웃한 위치입니다.
- 각 핀에 수축튜브를 씌우고, 소켓 뒤를 글루건으로 감싸 당김에 대비합니다(핀 사이로 흘러 들어가지 않게 소량만).
- 네 선은 가볍게 꼽니다.

## 4. 부저 리드선

WT-1205 + 핀에 빨강, − 핀에 파랑 28 AWG를 각 140 mm 납땜하고 수축튜브를 씌웁니다. 끝 5 mm는 피복을 벗기고 납으로 코팅합니다(나사 단자용).

## 5. 시험 (전달 전)

1. **도통**: 넷 표대로 각 연결이 0 Ω인지 확인합니다.
2. **단락 없음**: +5V_IN–GND 사이가 1 kΩ 이상인지 확인합니다.
3. **부저 동작**: 5 V 전원을 +5V_IN / GND에 연결하고, IO16 패드를 1 kΩ을 거쳐 3.3 V에 잠깐 댑니다. 부저에서 "딱" 소리가 나야 합니다(패시브 부저라 연속음이 아님).
4. **LID 단자**: TB2에 전선 두 가닥을 물리고 서로 대면 LID–GND가 0 Ω이 되는지 확인합니다.

## 6. 전달물

- 모듈 1개 (피그테일과 J1 소켓 포함)
- 리드선을 단 부저 1개
- 리드 센서 59155는 납땜하지 않은 원래 상태 그대로 (리드선을 TB2에 직접 물림)

## 7. 의뢰인이 할 일 (납땜 없음)

1. 부저를 하단 쉘 포켓에 넣고 글루건으로 한 점 고정합니다(+ 표시가 위).
2. 리드 센서를 벨트 포켓에 밀어 넣고 글루건으로 한 점 고정합니다. 리드선은 내부 커버 벽 바깥 틈으로 내립니다.
3. 부저 선을 TB1, 센서 선을 TB2에 넣고 나사를 조입니다.
4. 모듈을 내부 커버 바닥 아래(왼쪽 앞, CAD 표시 위치)에 1 mm 폼테이프로 붙입니다.
5. J1 소켓을 보드 J1에 꽂습니다(흰 점 = 보드 1번 핀 표시, 실물로 확인).
