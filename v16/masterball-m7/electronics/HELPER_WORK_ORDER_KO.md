# 전자배선 외주 의뢰서 (H1·H2·H3, 2026-11-16)

이 문서는 도우미·학교·외주에 그대로 전달하는 **의뢰 목록과 검수 기준**입니다.
- 작업 방법의 세부는 `electronics/HELPER_BUILD_KO.md`에 있습니다.
- 그림 2장을 함께 보냅니다:
  - `img/h1_option_a_wiring.png`: H1 최종 위치
  - `img/m7_wiring_v06.png`: 전체 배선도

**의뢰인 조건**
- 의뢰인은 납땜하지 않습니다.
- 의뢰인에게 **멀티미터가 없습니다**. 그래서 원래 의뢰인이 하던 J10 선 확인(S3a)과 전원 검사(P2·P3)도 도우미에게 맡깁니다. 이 작업에는 보드를 함께 보냅니다.

## 3. 하지 말아야 할 것

1. **4424를 원래 핀 배열 그대로 보드와 모듈에 동시에 꽂지 않습니다.** 3V3과 GND가 엉뚱한 핀에 닿아 역전원이 됩니다.
2. 모듈 Gravity 소켓이나 VCC 패드에 3.3 V보다 높은 전압(5 V 포함)을 주지 않습니다.
3. ESP32 보드에 납땜하거나 펌웨어를 다시 쓰지 않습니다. 보드는 꽂아서 측정만 합니다.
4. 스피커 리드와 리드 센서 리드를 자르지 않습니다. 길이가 배선 경로에 맞춰져 있습니다.
5. DFR0534의 장착 구멍 2개(SPK 쪽 끝)를 납·글루로 막지 않습니다.

## 4. 작업 순서

| 단계 | 내용 | 기준 문서 |
|---|---|---|
| 1 | **H3**: 스피커 + → SP+, − → SP−. 리드를 패드 근처에서 한 바퀴 감아 당김을 막습니다 | `HELPER_BUILD_KO.md` H3 |
| 2 | **H2**: 소켓 1번 모서리에 흰 점. 리드 → 10번, 6번. Ø1.5 수축튜브, 뒷면 글루 아주 조금 | `HELPER_BUILD_KO.md` H2 |
| 3 | **H1 선 확인 (S3a)**: 전원 OFF로 4424 SH 플러그를 보드 J10(USB-C 바로 옆)에 꽂습니다. PH 쪽 4선을 측정으로 구별합니다 ↓ | `docs/07` S3a |
| | ① USB-C 쉘과 0 Ω인 선 = **GND** | |
| | ② USB 연결(ON) 후 GND 기준 3.25–3.35 V인 선 = **3V3** | |
| | ③ 전원을 넣고 **10초 안에 화면을 길게** 누르면 화면에 "배선 시험 60초"가 나옵니다. 그동안 0 V로 떨어지는 선 = **GPIO44** | |
| | ④ 남은 선 = GPIO43 (쓰지 않음) | |
| 4 | **H1-A 재배열**: 전원 OFF. PH 하우징에서 접점 4개를 빼서 GND → "−", 3V3 → "+", GPIO44 → "R"로 다시 꽂습니다. "T"는 비웁니다. GPIO43 접점은 Ø1.5 수축튜브로 끝 5 mm 넘게 덮고 접어서 Ø3 수축튜브로 고정합니다 | `HELPER_BUILD_KO.md` H1-A, `img/h1_option_a_wiring.png` |
| 5 | **P1–P3 검사** (아래 표 H1-1 ~ H1-6) | `docs/04` §6 |
| 6 | **책상 시험** (선택, 아래 S-1 ~ S-3): 모든 검사를 통과한 뒤에만 케이블을 모듈에 꽂고 전원을 넣습니다 | `docs/07` S3d |

- "R/T/−/+"는 **모듈의 실크 글자**를 기준으로 합니다(공식 치수도 V1.0: 왼쪽 가장자리 위→아래 T, R, −, +).
- **선 색은 믿지 않습니다.**
