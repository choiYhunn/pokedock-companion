# G1 보드 실측 · G2 핏 키트 검사 절차 (작업자용)

이 절차를 모두 통과하기 전에는 외장 본 출력을 발주하지 않습니다.

- 측정값은 `docs/G1_G2_RECORD_TEMPLATE.csv`에 적습니다.
- 사진 파일명은 아래 표의 `ID.jpg`로 저장합니다(예: `G1-P3.jpg`).

## 준비물

| 구분 | 품목 |
|---|---|
| 측정 | 디지털 캘리퍼(0.01 mm), 틈새 게이지(0.20 / 0.30 / 0.50 mm), USB 전류·전압계(USB-C 인라인형), 멀티미터 |
| 촬영 | 휴대폰 카메라, 흰 종이 배경, 자(mm 눈금), 데스크 조명 1개 |
| PC | Windows PC + USB-C 케이블(데이터 지원), ESP-IDF v5.3.2(또는 `esptool`) |
| 기타 | 정전기 방지 장갑(또는 맨손 접지), 마스킹 테이프, 네임펜 |

### 사진 공통 규칙

- 보드는 흰 종이 위에 올립니다.
- 자를 같은 평면에 두고, 카메라는 정면에서 수직으로 30 cm 거리에서 찍습니다(줌 2배 이하).
- 그림자가 생기지 않게 조명을 비스듬히 둡니다.

### 소켓 선택 (G1-M6 결과로 결정)

- J1 헤더 양 끝에서 버튼까지의 틈이 0.25 mm 이상이면 몸체 길이 **≤ 9.2 mm**인 1.27 mm 2×7 암 소켓을 사용합니다.
- 틈이 0.25 mm 미만이면 소켓 대신 J1의 필요한 핀 6개(1, 3, 4, 6, 8, 그리고 GND 여유 핀)에 1.27 mm 단일 핀 하우징을 쓰거나, 납땜 하네스를 사용합니다. 이 경우 수축튜브로 절연합니다.

### G1 판정

- G1-M1–M4, G1-E1–E2, G1-E4–E8 전부 합격이어야 G2로 넘어갑니다.
- 치수가 불합격이면 CAD 파라미터를 고친 뒤 `tests/run_all.sh`(간섭·공차)를 다시 통과시킵니다.
