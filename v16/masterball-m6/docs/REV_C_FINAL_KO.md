# M6 Rev C — Release Candidate (G1 개발 보드·소형 부품 주문용)

- 실물 착수 절차: **`G1_START_HERE_KO.md`**
- 구매 목록: `procurement/BOM_M6.csv`(`tier` 열)
- 자동 검사 결과: **`tests/logs/RUN_MANIFEST.json`**(strict 실행, 소스 지문 포함). 이 문서에는 PASS 숫자를 적지 않습니다. 문서를 고치면 지문이 바뀌어 매니페스트가 무효가 되기 때문입니다.

## 1. 수정 전후 차이

| 항목 | Rev B | Rev C | 근거 |

## 2. 부저 구동 기판 (24×18×10 mm)

- **위치**: 하단 쉘 내벽, 방위 −110°·고도 −28°(왼쪽 뒤 아래). 받침 패드 2개 위에 1.0 mm 폼테이프로 붙입니다. 접착 면적은 2×5×18 = 180 mm²이고, 기판 무게는 약 3 g입니다(추정).
- **자동 확인** (`driver_board_check.py`):
  - 주변 부품(USB 보드, 부저, 나사, 웨이트, 소켓)과 2 mm 이상 떨어짐
  - 내벽 방향 삽입 경로에 충돌 없음
  - 디스플레이 서브어셈블리와 상단 쉘이 내려오는 경로와 겹치지 않음
  - 패드 사이 리드 공간 확보
  - 배선 길이 충분
- **실물로 확인할 것(UNVERIFIED)**:
  - 실제 부품 높이: 눕혀 조립해 ≤ 8.4 mm 목표
  - 리드는 1.0 mm 이하로 자르고 뒷면에 캡톤 절연
  - 폼테이프 접착력: PLA 표면을 IPA로 닦고 30초 압착, 필요하면 핫멜트로 보강
  - 배선을 당겼을 때 탈락하지 않는지

## 3. 공차 표기

- `cad/tolerance_stack.py`의 수치는 **가정한 분포**(구멍 0 ~ −0.25 mm, 벽 0 ~ −0.20 mm, PLA 0.2–0.5 %, PETG 0.3–0.8 % 수축)에서 나온 **모델 값**입니다. 업체 출력기로 측정한 통계가 아닙니다.
- 버튼 개구부(0.60 mm)는 **최악 조합에서 −0.111 mm 간섭**이 남습니다. 판정은 G2-K7(0.30 게이지)과 K11(외관 사진)에서 합니다.
- 0.60 mm 틈은 50 cm에서 약 4 arcmin이고, 검은 베젤과 이어져 보일 것으로 예상합니다(UNVERIFIED). 그래서 CAD는 바꾸지 않았습니다.

## 5. RTC·알람 제약

- 메인 배터리와 백업 셀이 없으므로 **전원이 끊기면 시계가 초기화되고, 전원이 끊긴 동안의 알람은 보장하지 않습니다.** 기상용 알람으로 단독 의존하지 마세요.
- 전원 복구 후: `--:--`와 "시간 맞춰줘"가 표시되고, 동기화 전까지 알람은 비활성입니다. 앱이 연결되면 자동으로 동기화합니다.
- **앱이 없으면 시계를 복구할 방법이 없습니다**(기기 단독 시간 설정 UI 없음). 집중 타이머와 반응 기능은 그대로 동작합니다.
- 지난 알람이 늦게 울리지 않는지, 다음 날 1회만 울리는지는 시뮬레이션 E2E로 확인했습니다. 실기는 G1 8번 단계에서 확인합니다.
- Wi-Fi NTP는 SSID 설정과 네트워크 의존성이 생겨 이번 범위에서 제외합니다.
