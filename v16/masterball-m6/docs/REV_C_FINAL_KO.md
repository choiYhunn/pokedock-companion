WT-1205 코일 최대 전류는 5.25 V / 40 Ω = 131 mA인데, 이 영역은 VCE = 1 V 활성 영역에서 hFE ≥ 30만 규정됩니다. ## 공차 표기 정정

- `cad/tolerance_stack.py`의 수치는 **가정한 분포(구멍 0 ~ −0.25 mm, 벽 0 ~ −0.20 mm, PLA 0.2–0.5 %, PETG 0.3–0.8 % 수축)**에서 나온 **모델 값**입니다. 실제 업체 출력기로 측정한 통계가 아닙니다.
- 버튼 개구부(간극 0.60)는 최악 조합에서 **−0.111 mm 간섭**이 남습니다. 따라서 "최악 공차 완전 통과"가 아닙니다. 판정은 **G2-K7(0.30 게이지)과 K11(외관)**에서 합니다.
- 0.60 mm 틈은 50 cm에서 약 4 arcmin입니다. 검은 베젤 옆의 어두운 틈이라 베젤 일부처럼 보일 것으로 예상합니다(**UNVERIFIED → G2-K11 사진으로 판정**). 그래서 CAD는 바꾸지 않았습니다.

## USB·전원 (계산·문서 근거)

- **PTC MF-R075 홀드 전류**: 23 °C 0.75 A, 50 °C 0.54 A, 70 °C 0.41 A. 예상 최대 부하는 약 0.3 A(**UNVERIFIED → 9번 단계 실측 < 400 mA**).
- **전압 강하**: 최악 0.21 V(R1max 0.60 Ω × 0.35 A).
- **D+/D− 170 mm**: Full-Speed라 전기적 길이가 문제 되지 않습니다. 꼬임쌍으로 만들고 부저 배선에서 10 mm 떨어뜨립니다(**UNVERIFIED → G1-E7**).
- **케이블**:
  - 외부 플러그 경로와 책상 사이 21 mm
  - 케이블은 뒤쪽으로 빠지므로 굽힘 반경에 제한이 없음
  - 내부 하네스는 뒤쪽 M3 기둥에 타이로 묶고 4090 패드는 핫멜트로 고정
- **연결·분리 영향**:
  - 배터리가 없으므로 분리하면 전원이 꺼지고, 연결하면 콜드 부팅합니다(RTC 미신뢰로 표시).
  - PC 시리얼 프로그램이 DTR/RTS를 토글하면 리셋될 수 있습니다(USB-JTAG 특성). 일반 충전기에서는 해당하지 않습니다.
- **이중 포트 실수 가능성**:
  - 사용자: 조립 후 보드 포트가 구체 안에 있어 사실상 불가능합니다.
  - 제작자: G1 벤치와 정비 때 가능합니다. 방지책은 먼지마개, 라벨, 그리고 "J1 소켓을 뽑은 뒤 보드 포트 사용" 절차입니다.
  - 다이오드 OR-ing은 VCC를 약 3.6 V로 낮추고 보드 쪽 역급전은 막지 못해 채택하지 않았습니다.

## RTC·알람 제약 (문서화)

- 메인 배터리와 백업 셀이 없으므로 **전원이 끊기면 시계가 초기화**되고, **전원이 끊긴 동안의 알람은 보장하지 않습니다.** 기상용 알람으로 단독 의존하지 마세요.
- 전원 복구 후: `--:--`와 "시간 맞춰줘"가 표시되고, 동기화 전까지 알람은 울리지 않습니다. 집중 타이머와 반응 기능은 그대로 동작합니다.
- 복구 방법: 휴대폰 앱이 연결되면 자동으로 시간을 동기화합니다. **앱이 없으면 시계를 복구할 방법이 없습니다**(기기 단독 시간 설정 UI 없음).
- 지난 알람이 늦게 울리지 않는지, 다음 날 1회만 울리는지는 시뮬레이션 E2E 16/16으로 확인했습니다. 실기는 G1 8번 단계에서 확인합니다.
- 선택 제안(미구현): Wi-Fi NTP는 SSID 설정 UI와 네트워크 의존성이 새로 생겨 이번 범위에서 제외합니다.

## 남은 실기기 위험 (모두 UNVERIFIED)

1. 패널 종류와 터치 칩 ID, 화면·터치 방향 (G1-E4–E6)
2. J1 경유 USB 열거와 플래시 안정성 (G1-E7)
3. 부저 음량과 부팅 중 무음 (G1-E8)
4. BLE 실제 본딩과 V17 앱 통합(통합 빌드는 아직 없음) (G1-E9)
5. 실소비전류와 PTC·보드 발열 (9번 단계)
6. FDM 실제 공차와 버튼 틈 외관 (G2)
7. 포켓몬 애니메이션 자산 미확보 (G5)
