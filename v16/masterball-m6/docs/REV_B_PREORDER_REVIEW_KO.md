# M6 Rev B — 부품 주문 전 최종 검토 (2026-10-24)

> **Rev C에서 일부 내용이 바뀌었습니다**(`REV_C_FINAL_KO.md`): 부저 구동이 2N3904에서 AO3400A로 바뀌었고, 아래 "간섭 확률"은 가정한 분포에서 나온 모델 값일 뿐 실측 통계가 아닙니다.

범위: 제조와 전자회로 위험에 한정했습니다. **UI와 외관 디자인은 바꾸지 않았습니다.** 단, 버튼 둘레 틈새가 0.35 mm에서 0.60 mm로 넓어졌습니다(1번 항목 참조).

## 1. 공차: FDM 오차와 수축을 실제로 반영했는가

**결론: Rev A는 부족했습니다.**
- 기존 `verify_m6.py`는 면마다 ±0.15 mm를 대칭으로 가정한 기하 검사였습니다.
- 실제 FDM은 바깥벽이 부풀고(0 ~ −0.20 mm), 구멍은 작게 나오며(0 ~ −0.25 mm), 재료별로 수축합니다(PLA 0.2–0.5 %, PETG 0.3–0.8 %).
- 여기에 나사 유격과 상·하 쉘 유격 같은 조립 위치 오차가 더해집니다.

이 요소들을 따로따로 넣은 `cad/tolerance_stack.py`를 새로 만들어 분석했습니다(최악값 + 몬테카를로 20만 회).

## 2. 하네스: 공식 회로도와 독립 대조

- 내부 JSON끼리만 맞추는 검사로는 승인하지 않기로 했습니다. 그래서 `tests/schematic_netlist_check.py`를 만들었습니다. 이 검사는 **Waveshare PDF 안에 들어 있는 Altium 넷리스트 텍스트(PI핀 / NL넷)를 직접 파싱**합니다.
- 결과 9/9 PASS:
  - J1-4 = USB_5V = J4 VBUS(A4/B9, A9/B4) = ETA6098 VIN
  - J1-6 = GND
  - J1-1 = U_P = DP1/DP2(22 Ω R19 앞)
  - J1-3 = U_N = DN1/DN2(R18 앞)
  - J1-8 = IO16(U4 22번 핀)
  - J1-2·J7-1 = VBAT(미사용)
  - J2-1 = PCF85063 VDD = D1 캐소드
  - J2-2 = GND
- 음성 대조: J1-5는 IO6, J1-7은 IO5, J3-13은 3V3, J3-2는 IO18로 판독됩니다. 파서가 다른 넷을 서로 구분한다는 확인입니다.
- 회로도 그림으로도 다시 확인했습니다(`docs/img/vendor_schematic_*.png`). D2 MBR230은 **USB_5V → VCC** 사이에 있습니다. Q1(AO3401)의 바디 다이오드 방향 때문에, 배터리가 없을 때 VCC에서 VBAT로 역류하지 않습니다.

## 4. 터치 컨트롤러 변형

- Waveshare 공식 문서는 FT3168을 표기합니다. FT6146 계열도 같은 FocalTech 레지스터 맵을 씁니다(0x02 TD_STATUS, 0x03–0x06 P1 좌표). 공식 데모도 이 레지스터만 사용합니다.
- 펌웨어는 부팅할 때 칩 ID(0xA3), 벤더 ID(0xA8, FocalTech = 0x11), 펌웨어 버전(0xA6)을 읽어 로그에 남깁니다. 벤더가 FocalTech가 아니면 "UNKNOWN vendor - verify on G1"을 출력합니다.
- 지원 범위: I2C 0x38에 응답하는 FocalTech 단일 터치 계열(FT3168 / FT6146 / FT6x36).
- 0x38에서 응답이 없으면 오류 로그를 남기고 터치 없이 동작합니다(BLE 제어는 가능).
- 실제 칩 ID는 G1-E4에서 기록합니다.

## 5. 부저: 모든 곳에서 같은 사양

> **Rev C에서 대체됨.** 부저 자체(Soberton WT-1205, 5 V, 47±7 Ω, 2400 Hz, Ø12×9.5 ±0.5)는 그대로입니다. 하지만 Rev B의 NPN 구동(470 Ω 베이스 저항, "β=30이면 포화" 판단)은 2N3904 데이터시트의 포화 보증 범위(IC 50 mA)를 넘는 근거였습니다. 그래서 Rev C에서 **AO3400A + 100 Ω + 100 kΩ + 1N4148**로 바꿨습니다. 현재 회로와 근거는 `REV_C_FINAL_KO.md` §1·§4를 보세요.

## 6. RTC 백업 셀 제외와 무셀 복구

- J2는 3V3 → B5819로 **전류 제한 없이** 충전되므로 셀을 구매 목록에서 제외했습니다(BOM X2). G1-E3에서는 전압만 기록합니다.
- 셀 없이 정전된 경우: PCF85063 OS 플래그 → 시계 "미신뢰" → 화면에 "시간 맞춰줘" 표시, 알람 비활성(잘못된 시각에 울리지 않음). 설정·알람·메시지는 NVS에 저장되어 유지됩니다.
- 앱이 연결되면 시계가 미신뢰이거나 마지막 동기화가 12시간을 넘었을 때 **자동으로 time_sync**를 보냅니다(`PokeDockClient.connect`).
- E2E 시뮬레이션에 4개 시나리오를 추가했고 **16/16 PASS**입니다.
  1. 콜드 부팅 → 연결 시 자동 동기화
  2. 정전 → NVS 설정 유지 + 시계 미신뢰
  3. 시계를 모르는 동안 알람이 울리지 않음
  4. 알람 시각이 지난 뒤 재동기화 → 지난 알람은 울리지 않고, 다음 날 1회만 울림
- 한계: 정전 중이던 집중 타이머는 RAM에만 있어 초기화됩니다(설계상 허용). 실제 PCF85063의 OS 플래그 동작은 G1에서 USB를 뺐다 꽂아 확인합니다.
