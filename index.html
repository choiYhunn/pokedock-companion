Study tools

V1 기능

Focus / Pomodoro

15·25·45·60분 preset, pause/resume, 완료 시 공부시간과 세션 기록.

Timer / Stopwatch

일반 카운트다운과 lap 스톱워치를 공부 외 일상에도 사용.

Study Log

오늘/주간 공부시간, 세션 수, streak를 microSD/NVS에 저장.

Wi-Fi

NTP, 날씨, local web settings, OTA. 네트워크가 끊겨도 핵심 기능은 계속 동작.

Phone Bridge

선택 기능. 통화·일정·선택 연락처 같은 중요 알림 요약만 표시하고 본문은 저장하지 않음.

NFC / Dex

측면 피규어/태그로 테마·집중 buddy를 전환하고 공부 완료 보상과 연결.
