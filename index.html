Wi‑Fi를 넣는 이유

인터넷이 없어도 타이머·스톱워치·알람은 동작한다. Wi‑Fi는 “없으면 망하는 기능”이 아니라 일상 편의와 설정을 확장하는 계층으로 쓴다.

V1NTP 시간 동기화

RTC를 자동 보정해서 시계를 직접 맞출 필요가 없다.

V1날씨 / 현재 상태

간단한 날씨를 받아 홈 화면과 등장 포켓몬 테마에 반영.

V1폰 웹 설정

별도 앱 설치 없이 같은 Wi‑Fi에서 브라우저로 알람, 과목, D‑day, 포켓몬 선호를 수정.

V1OTA 업데이트

USB를 매번 꽂지 않고 펌웨어/설정을 업데이트하는 경로를 준비.

V2Calendar sync

Google OAuth를 ESP32에 직접 욱여넣기보다 iCal/relay 방식으로 나중에 추가.

V2Remote message

원하면 나중에 네가 보내는 짧은 메시지나 기념일 이벤트를 원격으로 동기화.

공부 보조 기능은 여기까지가 제일 좋다

기능을 많이 넣는 것보다 “실제로 하루에 여러 번 누르는 것”을 넣는다. 아래는 하드웨어 성능과 한 번의 제작일을 동시에 고려한 V1 범위다.

COREPomodoro / Focus

25/5 기본, 15·25·45·60분 preset, 사용자 정의, 자동 휴식. Lucario가 Focus buddy.

CORETimer + Stopwatch

일반 카운트다운, lap 지원 스톱워치. 요리·운동·공부 모두 써먹을 수 있음.

COREStudy Log

완료 세션을 microSD에 저장하고 오늘/주간 총 공부시간, streak를 보여줌.

CORED‑day / To‑do

시험·과제·약속을 3~5개만 홈에 노출. 폰 웹페이지에서 편집.

COREAlarm / Bedside

RTC 기반 알람과 부드러운 화면/사운드. 밤에는 팬텀 테마와 저휘도 자동 전환.

FUNStudy EXP / Dex

집중 세션 완료 시 EXP 또는 encounter 확률 증가. 공부가 실제 포켓몬 콘텐츠를 열어줌.

왜 앱을 안 만드나?

생일 선물 한 대를 위해 Android/iOS 앱을 따로 유지하는 건 과하다. ESP32 자체가 작은 웹 서버를 열고, 같은 Wi‑Fi에서 휴대폰 브라우저로 설정하게 하면 앱 설치도 필요 없고 운영도 훨씬 단순하다.

기기 자체 UI는 “즉시 쓰는 기능”에 집중하고, 긴 텍스트 입력이나 D‑day 편집은 폰으로 넘긴다.
