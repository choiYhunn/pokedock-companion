UI Simulator

Simulator V6는 실제 800×480 기기 화면처럼 동작한다. 상시 내비게이션은 HOME / 집중 / 포켓볼 메뉴 세 개. 포켓볼을 누르면 팬텀의 비밀기지가 열려 네 기능 그룹을 안내하고, HOME에서 파트너 선택을 누르면 포켓몬 게임처럼 파티 선택 화면이 열리고, 픽셀 캐릭터의 등장·움직임을 감상한 뒤 확정할 수 있다. 팬텀을 터치하면 숨은 둘만의 서랍도 나타난다. 할 일·D-day·기념일·편지는 브라우저에서 직접 수정할 수 있다. 일부 수치와 연동은 데모 상태다.

현재 구현 범위

Study Core

Focus, Timer, Stopwatch, Today, Study Log, D-day/To-do.

BLE Phone Bridge

UI 시뮬레이션과 PhoneEvent/프레임 decoder까지. 실제 Android/iPhone adapter는 다음 단계.

Wi‑Fi

NTP, 날씨, 로컬 웹 설정, OTA. 네트워크가 없어도 핵심 타이밍 기능은 유지.

Dock

ESP32-C3 + NFC + 폰 감지 + 조도 + RGB. HMI와 ESP-NOW.

Qi

완제품 보호회로 충전기를 후면 경사 지지대 쪽에 기구적으로 통합.

Birthday

평소에는 실용 기기, 생일에만 별도 Secret Event가 가장 높은 우선순위로 동작.
