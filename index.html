현재 구현 범위

Study Core

Focus, Timer, Stopwatch, Today, Study Log, D-day/To-do.

BLE Phone Bridge

UI 시뮬레이션과 PhoneEvent/프레임 decoder까지. 실제 Android/iPhone adapter는 다음 단계.

Wi‑Fi

NTP, 날씨, 로컬 웹 설정, OTA. 네트워크가 없어도 핵심 타이밍 기능은 유지.

Dock

ESP32-C3 + NFC + 폰 감지 + 조도 + RGB. HMI와 ESP-NOW.

Qi

완제품 보호회로 충전기를 후면 경사 지지대 쪽에 기구적으로 통합.

Birthday

평소에는 실용 기기, 생일에만 별도 Secret Event가 가장 높은 우선순위로 동작.
